# Edition releases

RIDA editions have separate package/application versions. A shared product name does not mean their version numbers advance together.

| Edition | Version documented here | Distribution |
| --- | --- | --- |
| Python | 2.0.2 | [PyPI](https://pypi.org/project/rida-format/2.0.2/) |
| Node.js | 2.0.1 | [npm](https://www.npmjs.com/package/rida-format/v/2.0.1) |
| RIDA Studio for Mac | 2.0.2 | [GitHub Release](https://github.com/Qasraf/rida/releases/tag/studio-v2.0.2) |

## RIDA Studio 2.0.2

- Updated the final RIDA branding and rounded macOS application icon.
- Set the disk image volume icon and the local Finder DMG file icon.
- Developer ID signed, notarized by Apple and supplied with its approval ticket attached.
- Apple Silicon arm64 build.
- Includes source selection, scans, separate/shared/all group outputs, Auto setup suggestions, build settings, optional encryption, read/inspect tools and local processing.

Raw DMG downloads do not reliably preserve the Finder file's custom-icon metadata across all browsers/filesystems. The installed app's bundled icon is part of the app. A ZIP alternative preserves the DMG's Finder metadata when extracted with macOS tools.

For the full Python and Node release history, consult their public package pages and the changelog included in the package. No claim is made that these documentation examples were newly benchmarked on every operating system.
