# Download RIDA Studio

[Download RIDA.dmg — Apple Silicon](https://github.com/Qasraf/rida/releases/download/studio-v2.0.2/RIDA.dmg)

Version **2.0.2**, arm64, **macOS 12.0 or later**. Developer ID signed and notarized by Apple, with its ticket attached. Intel Macs are not supported by this build. See the [installation and app guide](../docs/MAC-APP.md).

The installer is hosted as a GitHub Release asset, not stored in this Git repository. [SHA-256 checksum](SHA256SUMS) is provided to identify the exact download.

```sh
shasum -a 256 RIDA.dmg
```

Compare its output with SHA256SUMS. A checksum identifies file bytes; Apple signing/notarization is separate.
