# Questions and contributions

Open a GitHub issue for documentation errors or reproducible package problems. Include the edition/version, OS, minimal generic JSON and exact command. Do not include real account credentials, environment files, decryption keys or private datasets.

This repository is the public documentation and examples hub. Python and Node packages are distributed through their registries. Software use and redistribution remain subject to the RIDA Proprietary License.

For security concerns, contact admin@qasra.org privately rather than posting sensitive material in a public issue.
